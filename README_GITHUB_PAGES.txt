ENSTALASYON SOU GITHUB PAGES
1. Kreye yon nouvo repository sou GitHub.
2. Louvri repository a, chwazi Add file > Upload files.
3. Louvri ZIP la sou telefòn/òdinatè a epi telechaje TOUT fichye ak katab ki anndan GITHUB_PAGES_BIB dirèkteman nan rasin (root) repository a. Pa telechaje yon lòt katab ki gen tout fichye yo ladan l.
4. Peze Commit changes.
5. Ale nan Settings > Pages.
6. Nan Build and deployment, chwazi Deploy from a branch.
7. Chwazi branch main ak folder /(root), epi peze Save.
8. Tann GitHub ba ou adrès sit la. Ouvri li nan Google Chrome sou telefòn Android.
9. Nan meni Chrome (⋮), chwazi Install app oswa Add to Home screen.

ENPÒTAN
- Kenbe estrikti fichye yo egzakteman jan yo ye a, espesyalman katab icons la.
- Pa mete fichye yo anndan yon lòt sou-katab nan repository a.
- GitHub Pages sèvi ak HTTPS, sa ki pèmèt manifest ak service worker aplikasyon an fonksyone.
- Kontni aplikasyon an pa modifye; fichye sa yo sèlman ranje nan rasin pou GitHub Pages.
