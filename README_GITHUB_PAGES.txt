GID LEKTI BIB LA — PWA KORIJEE V2

Kijan pou mete ajou GitHub Pages:
1. Dekonprese fichye ZIP sa a.
2. Louvri repository lekti-bib-la sou GitHub.
3. Chwazi Add file > Upload files.
4. Voye TOUT fichye ki anndan katab GID_LEKTI_BIB_PWA_KORIJEE_V2 la dirèkteman nan rasin repository a (pa mete katab sa a kòm yon lòt sou-katab).
5. Si GitHub mande pou ranplase fichye ki deja egziste yo, aksepte ranplasman yo.
6. Peze Commit changes epi tann GitHub Pages fini deplwaman an.
7. Ouvri sit la nan Chrome epi rafrechi li.

Fichye prensipal yo dwe chita menm nivo: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, kouveti-gid-lekti-bib-la.png.

Vèsyon sa a ajoute id eksplisit nan manifest lan, start_url ./, icons maskable, epi yon Service Worker ki pa echwe enstalasyon li si kach yon imaj opsyonèl pa mache. Sa se yon koreksyon kandida; apre deplwaman, tès enstalasyon Chrome a dwe konfime rezilta a.
